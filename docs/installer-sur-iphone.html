IRL LVP UP

Installer l’app sur ton iPhone

Cinq gestes dans Safari, et l’app est sur ton écran d’accueil — icône, plein écran, et elle marche sans réseau.

⏱️ 2 minutes

  1. Ouvre le lien dans Safari

    Pas Chrome, pas depuis Instagram ou Mail. Safari uniquement : sur iPhone, c’est le seul navigateur qui installe une vraie app.

    adrienlvl.github.io/irl-lvp-up/

  2. Touche le bouton Partager

    Le carré avec une flèche vers le haut, dans la barre en bas de l’écran. Si la barre a disparu, fais défiler vers le haut pour la faire revenir.

    Partager

  3. Fais défiler jusqu’à « Sur l’écran d’accueil »

    C’est assez bas dans la liste, sous les options de partage. L’icône est un carré avec un +.

    ⊞ Sur l’écran d’accueil

  4. Valide le nom, puis Ajouter

    Le nom proposé est déjà le bon. Touche Ajouter en haut à droite.

    ✓ Ajouter

  5. Lance-la depuis l’écran d’accueil

    L’icône est apparue sur ta dernière page d’applis. Ouvre-la depuis là, plus depuis Safari : c’est ce qui te donne le plein écran et le stockage durable.

Deux pièges qui coûtent cher

🔀 Tes données ne suivent pas toutes seules

L’app installée a son propre stockage, séparé de l’onglet Safari. Si tu as déjà saisi des choses dans l’onglet, elles n’apparaîtront pas dans l’app installée. Avant d’installer : Réglages → Exporter mes données dans l’onglet, puis Importer une fois l’app ouverte depuis l’écran d’accueil.

🗑️ C’est justement pour ça qu’il faut l’installer

iOS fait le ménage dans les données des sites que tu n’as pas ouverts depuis 7 jours. Un simple onglet Safari peut donc perdre ta progression. Une app posée sur l’écran d’accueil échappe à ce ménage.

Ce que tu gagnes

  • →Plein écran — plus de barre d’adresse ni d’onglets.
  • →Hors-ligne — dans le métro, en salle, en sortie trail : tout est déjà sur le téléphone.
  • →Stockage durable — ta progression ne s’efface plus toute seule.
  • →Raccourcis — un appui long sur l’icône ouvre directement Ma journée ou Ma séance.

Si ça coince

  • →« Sur l’écran d’accueil » est introuvable — tu n’es pas dans Safari. Copie le lien et rouvre-le depuis Safari.
  • →L’app s’ouvre vide — c’est normal, c’est un stockage neuf. Importe ta sauvegarde (piège n°1).
  • →Une vieille version s’affiche — ferme l’app complètement (glisse-la vers le haut dans le sélecteur), puis rouvre-la.
Une fois installée, l’app se met à jour toute seule quand tu l’ouvres avec du réseau. Garde l’habitude d’exporter ta sauvegarde de temps en temps : c’est la seule copie qui existe, tout reste sur ton téléphone.
